# Changelog

## 0.1.0

- Initial Occult Horrors library release.
- Added 32 original staged afflictions from levels 0–20.
- Added dream, mental, shadow, parasite, mutation, corruption, and necrotic themes.
- Added mixed curse, disease, and poison content.
- Added semantic Creature Forge tags using contract 1.0.0.
- Added DE/EN localization.
- Added Foundry 14-safe managed compendium synchronization.
- Added schema, localization, semantic-tag, content-coverage, portability, and runtime smoke tests.
